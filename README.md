# Домовик: Усадьба

Оригинальная браузерная cozy idle/management игра на Phaser 4 + TypeScript.

## MVP
- строительство усадьбы;
- 5 типов зданий;
- пассивная экономика;
- персонаж Лёва с idle-анимацией;
- анимации появления и покачивания построек;
- XP и уровни;
- задания;
- офлайн-прогресс;
- локальное сохранение.

## Запуск
```bash
npm install
npm run dev
```

## План
1. Полировка UX и мобильного интерфейса.
2. Производственные цепочки и апгрейды зданий.
3. Диалоги и сюжетные квесты.
4. Yandex Games SDK: облачные сохранения, rewarded video, fullscreen ads, лидерборды.
5. Баланс экономики и аналитика retention.

Реклама должна вызываться только через SDK и в логических паузах; rewarded video — только по явному действию игрока, согласно требованиям Яндекс Игр.
